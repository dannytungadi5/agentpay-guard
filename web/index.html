How it works

1. The owner keeps the funds and approves the guard once. 2. Each agent gets its own budget, per-payment cap, expiry, 24h limit and list of shops. 3. Optional: big payments wait for the owner to approve, and invoices must be signed by the merchant. 4. Every order id pays once. No admin, no fee. 5. One call revokes an agent.
